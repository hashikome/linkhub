# ADR-0002: Immutable UUIDv7 identities; mutable names never in contracts

**Status:** accepted; pretty collection URL allowance superseded by [ADR-0053](0053-id-only-collection-addresses.md)
**Date:** 2026-10-07

## Context

Handles, display names and emails change. Anything durable keyed on them breaks
on rename and leaks personal data into URLs and foreign keys.

## Options considered

- Natural keys (handles, emails)
- Immutable UUIDv7 ids everywhere durable, mutable values only for display

## Decision

Database identities are immutable UUIDv7 values generated by `app_uuid_v7()`.
Hub handles, display names and emails never appear in authorization rules,
foreign keys or route contracts. Durable links use ids (`/c/<id>`, `hubId`);
pretty URLs (`/@handle/slug`) are allowed to break on rename.

## Rationale

- Renames never break saved references.
- Time-ordered ids keep inserts and cursors efficient.

## Constraints to preserve

- Permalinks and stored references use ids.
- Audit and logs record ids, never mutable names.

## Audit presentation clarification (2026-10-09)

Audit identities remain full immutable UUIDs without cascading entity references.
Current usernames are read-time labels, not historical snapshots. Lookup inputs
resolve to IDs before continuation; a hub filter identifies the recorded hub,
never its owner. Event-time hub context is retained where known; legacy unknown
context stays unknown. Suffix abbreviations expand to full references and are
never accepted as identity keys. This applies the existing decision rather than
replacing it; details live in [service operations](../design-docs/service-operations.md#audit-identity-and-filtering).


## Amendment (2026-10-10)

[ADR-0033](0033-permanent-hub-handles-and-self-service-accounts.md) introduced
self-service account lifecycle and retained handle reservations. Its permanent
handle rule was superseded by [ADR-0042](0042-editable-hub-handles.md), then
[ADR-0043](0043-deliberate-hub-handle-changes.md) settled the current policy:
30 days between handle changes, with retired spellings never reusable by anyone.
Person username rules are separate. [ADR-0041](0041-fixed-account-email.md) fixes
account email pending a dedicated identity-change workflow; immutable UUIDs
continue to own references and authorization. Self-service lifecycle remains
accepted, with contextual recovery under [ADR-0040](0040-contextual-account-recovery.md).
